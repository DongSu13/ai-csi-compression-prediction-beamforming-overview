# CSI 压缩、预测与未来波束选择

[中文](README.md) | [English](README.en.md)

本项目探索在有限数字反馈和候选扫描预算下，联合完成信道状态信息（CSI）压缩、未来信道预测与码本波束选择。

本仓库目前仅提供项目概览，作为后续公开内容的入口。源码、数据、模型权重和详细实验档案尚未发布。

## 研究问题

终端测得的 CSI 需要反馈给基站，而反馈带宽有限，移动信道也会随时间变化。本项目关注：如何利用压缩后的历史信息，在恢复和预测 CSI 的同时，为未来时刻选择少量候选波束。

研究同时考虑反馈量、CSI 重构与预测质量、候选扫描成本，以及计算时延。

## 方法概览

```text
终端：历史 CSI → 编码与量化 → 数字反馈包
基站：解析反馈 → 因果历史建模
                  ├─ 当前 CSI 重构
                  ├─ 未来 CSI 预测
                  └─ 未来候选波束选择
```

项目从三个任务的独立基线逐步发展到共享表示与多任务模型。主要研究内容包括多尺度量化编码、物理预测与学习模型融合，以及面向波束效用的联合训练。

这里的波束选择基于固定码本，目标是在有限候选扫描下保留较高的接收功率。

## 当前研究状态

已有仿真评估显示，共享模型相对同反馈和同候选扫描预算下的适配独立串联系统，可以提高未来波束的功率保留，但未来 CSI 预测存在指标权衡。

当前结果适用于已评估的仿真场景。连续执行仍有时延与排队约束，尚未完成真实射频或实时部署验证，也不据此宣称三个任务全面优于现有方法。
